# BEL KI - Wahrheit ohne Kompromiss

Eine revolutionäre deutsche KI-Initiative, die auf radikaler Ehrlichkeit, 100% Offline-Betrieb und vollständiger Transparenz basiert.

## 🎯 Über das Projekt

**BEL KI** ist ein Llama-3.1-8B Modell, finetuned auf dem GermanQuAD-Datensatz mit einer finalen Loss von 0.53 - trainiert auf einer RTX 3070 von Belkis Aslani (aka Beat to the Kiss).

### Kernwerte
- ✅ 100% Offline & Lokal
- ✅ Keine Zensur
- ✅ Kein Cloud-Zwang
- ✅ Radikale Ehrlichkeit

## 🚀 Technologie

- **Modell**: Llama-3.1-8B
- **Datensatz**: GermanQuAD
- **Hardware**: RTX 3070
- **Format**: GGUF (Q4_K_M)
- **Final Loss**: 0.53
